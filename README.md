# Customer Churn Prediction

## Project Overview
This project was developed as part of a university Machine Learning course. The goal was to predict customer churn using telecommunications customer data.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Project Workflow
- Data cleaning and preprocessing
- Handling missing values
- Categorical feature encoding
- Train-test splitting (80/20)
- Training Logistic Regression and Random Forest models
- Model evaluation and comparison

## Results
The best model achieved an accuracy of 79.67%.
